Revisar un archivo

Un archivo de un subcontratista — se revisa, no se consolida.

Para qué sirve

  • Revisa un archivo .xlsx a la vez y avisa de lo mismo que detecta la consolidación: duplicados, fechas ilegibles, códigos fuera de dominio, columnas faltantes, filas rechazadas.
  • No genera ningún reporte y no guarda nada. Sirve para corregir el archivo antes de ponerlo en el zip del mes.
  • Se puede usar aunque haya una consolidación en curso: no interfiere.
  • Para el zip completo del mes use la página principal.

Periodo

Las fechas se revisan contra este periodo, igual que en la consolidación.
